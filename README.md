# 📱 QRConverter-WEB

QRConverter-WEB is a simple and lightweight **web-based QR code converter** built with a plain **server–client architecture**.  
The project is designed as a basic and straightforward implementation for learning and demonstration purposes.

---

## 🚀 Features (v1.0.0)

- 🔗 Generate QR codes from text or URLs  
- 🌐 Runs directly in the browser  
- ⚡ Fast and easy to use  
- 🧩 Simple structure without complex frameworks  

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript**
